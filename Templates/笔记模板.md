## 字段说明（使用时删除本段）

- `title`：笔记标题
- `source`：原文链接
- `site`：来源站点，如 少数派 / 知乎 / GitHub / 微信公众号
- `author`：作者（可空）
- `published`：原文发布日期，格式 YYYY-MM-DD（可空）
- `collected`：抓取日期，格式 YYYY-MM-DD
- `status`：`inbox`（稍后读）或 `done`（已总结归档）
- `favorite`：`true` 表示收藏/重点，`false` 否
- `topics`：所属分类，取 Notes 下的文件夹名：生活 / 家居 / 爱好 / 专业-科技 / 职场 / 其他
- `tags`：标签列表，如 `[AI, 效率, 读书]`
